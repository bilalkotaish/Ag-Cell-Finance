# 💰 AG Cell Finance

A modern finance management web application designed to simplify personal financial tracking with an intuitive, responsive, and user-friendly interface.

## 🌐 Live Demo

https://ag-cell-finance.vercel.app/

## ✨ Features

* Secure User Authentication
* Dashboard Overview
* Income & Expense Tracking
* Financial Analytics
* Responsive Design
* Clean & Modern UI

## 🛠️ Tech Stack

**Frontend**

* React.js
* Tailwind CSS
* JavaScript (ES6+)

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB
* Mongoose

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/ag-cell-finance.git

cd ag-cell-finance

npm install

npm run dev
```
